# لوحة مالك ضماني — نموذج عرض فقط

هذه مواصفات واجهة إدارية مستقبلية، وليست صفحة منشورة أو لوحة صالحة للاستخدام التجاري.

## الأقسام
1. **طلبات الشراء:** رقم الطلب، مرجع الدفع، الحالة، تاريخ الطلب، وقت الاعتماد، الموظف المعتمد. إجراءات اعتماد الدفع أو رفضه تتطلب صلاحية المالك والتحقق المستقل من وصول المبلغ.
2. **التراخيص:** معرف الترخيص، الطلب المرتبط، الحالة، رقم المراجعة، هل الجهاز مربوط، تاريخ آخر تحقق. لا تعرض بصمة رمز التفعيل أو المفتاح العام الكامل للجهاز.
3. **سجل العمليات:** نوع العملية، معرف الطلب أو الترخيص، منفذ العملية، الوقت، مع ترقيم الصفحات.
4. **نقل الترخيص:** يبدأ بموافقة المالك، ثم تحدٍّ رقمي يوقعه الجهاز الجديد؛ لا توجد أزرار نقل مباشر تتجاوز الإثبات.

## ضوابط التنفيذ
- دخول المالك بحساب شخصي ومصادقة متعددة العوامل وجلسات قصيرة، وفصل أدوار المشاهدة عن الاعتماد.
- لا تضع رمز الإدارة أو مفتاح التوقيع أو الاتصال بقاعدة البيانات في الواجهة الأمامية.
- كل استعلام يتم من خادم مصادق عليه، مع تحقق الصلاحيات في كل طلب، وليس بإخفاء أزرار فقط.
- سجل تدقيق مستقل للعمليات الحساسة مع مراجعة دورية.
- لا ترسل صور الفواتير أو النصوص المستخرجة منها أو بيانات الضمان إلى خادم التراخيص.
- عمليات الشراء والنقل والإيقاف تحتاج اختبارات وصول وتزامن ورفض ونسخ احتياطي قبل النشر.

## الحالة
أُضيفت استعلامات قراءة مُرقّمة في `postgres/repository.mjs` للطلبات والتراخيص والأحداث. لم تُنشأ واجهة دخول أو لوحة مستخدم فعلية بعد.
